# BeautyFlow — Documentação para Codex

Este pacote contém a documentação de produto, frontend, backend, arquitetura, segurança, qualidade e tarefas detalhadas para produzir o MVP mobile do BeautyFlow com apoio do Codex.

## Como usar com Codex

1. Copie a pasta `docs/` e `specs/` para a raiz do repositório.
2. Abra o Codex na raiz do projeto.
3. Leia primeiro `docs/00_codex_context.md`.
4. Depois siga a ordem:
   - `specs/001-beautyflow-mvp/spec.md`
   - `specs/001-beautyflow-mvp/plan.md`
   - `specs/001-beautyflow-mvp/tasks.md`
5. Execute as tasks em pequenos lotes, revisando cada entrega.
